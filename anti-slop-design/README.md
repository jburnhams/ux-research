## Files stored

- `SKILL.md`: "the one rule", a six-step operating protocol, instant rejects, the
  reference routing table, severities and non-negotiables.
- `13-pre-emit-checklist.md`: the gate run before emitting.
- `15-product-types.md`: personality axes and the starting register for each
  product category ("falling back to B2B SaaS is what produces the generic page").
- `09-code-patterns.md`: markup, tokens, styling architecture.

## What is distinctive

- **"State your choices."** The protocol ends: "Close with 3–6 lines naming the
  deliberate decisions and why. If you cannot justify a choice, it was slop." It is
  a cheap, checkable output contract.
- **A named competitor not to look like** is part of the brief.
- **Each module ends in a "Quick audit" grep list**, so the anti-pattern database
  carries its own detection strings.
- It goes beyond visuals into data visualisation honesty ("a bar chart whose y-axis
  does not start at zero", "chart values available only in a hover tooltip") and
  mobile platform rules ("one identical design shipped to both iOS and Android").
- Caution: "Durable: defensible in two years, not tied to a 2024–2026 trend cycle"
  sits alongside a list of 2024–2026 trends it bans. Every tell list is tied to its
  own era, and taste-skill is the only source that dates its list.
